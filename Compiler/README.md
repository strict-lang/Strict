# Strict.Compiler
Builds native executables: `NativeBuild` behind `strict build` turns the instructions of all used types into MLIR (`MlirModule`, one `MlirFunction` per method with `MlirStatements`, `MlirCalls`, `MlirLoops` and friends, `MlirKernel` and `MlirFastLoop` add a copy without per element checks to simple loops over lists, LLVM vectorizes it), adds the runtime written directly in MLIR (`NativeRuntime.mlir` for texts, lists, files, processes and the garbage collector, `NativeRuntimeWindows.mlir` or `NativeRuntimeLinux.mlir` for the platform) and runs mlir-opt, mlir-translate and clang (`Toolchain`, `ToolRunner`).

`Bootstrap.mlir` is the seed, the compiler compiled by itself: `Bootstrap.cmd` (Windows) and `bootstrap.sh` (Linux) build a first `strict` from it, which then builds itself. A native executable runs 1M loop iterations in 40 ms.
