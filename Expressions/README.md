# Strict.Expressions
Understands Strict source: `Tokenizer` and `SyntaxParser` turn lines into syntax trees, `BodyParser` and `StatementParser` read method bodies (`NamedIterators` unrolls `for y, x in Height, Width` into the nested loops of `value` and `outer` before anything else sees it, `CountedIterators` number literals into one loop: `for y, x in 8, 8` is `for 64` with `let y = (index / 8).Floor`), `TypeShape` the structure of a type file (members, methods, constants, traits), `KnownTypes`, `Instantiation` and `TypeInference` know the types of all packages, `ResolveCheck` reports unknown names and methods (`NameNotFound`, `MethodNotFound`) with file and line before anything runs.
