# Strict.Xml
Xml keeps the text of an element (or a whole file, `Xml.Read(path)`) and reads it on demand, enough for the content, level, settings and animation files of the C# DeltaEngine: `Name` of the element (the `<?xml ?>` prolog, comments and a byte order mark are skipped), `Attribute(key)` returns the quoted value of its start tag (empty when missing, also across lines), `Values(key)` the numbers in it (`"0 0.5 0 0"` or `"(1.00, 0.50, 1.00, 1.00)"`), `Children` the direct child elements, `xml(name)` (its `get(name)`) the first one with that name (an empty Xml when missing) and `Content` the trimmed text inside (`<MusicVolume>0.75</MusicVolume>`). The five predefined entities (`&amp;`, `&lt;`, ...) are decoded. A single line like `<ContentData Name="Hero" />` or an attribute fragment works too.

Not supported: single quoted attributes, `>` inside an attribute value, CDATA and numeric character references. Every call scans the text again, so keep the Xml of a child instead of asking the root repeatedly. `Settings.xml` (DeltaEngine) and `Animation.xml` (SoulCraft, shortened) are real files used by the tests.
