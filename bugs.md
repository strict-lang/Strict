# Bugs
- `Runtime/Frame.strict` `Finished` has 12 production lines (`ProductionLinesMustNotExceedTen`): a helper for the slot write and the `Changing` spread made the VM loop 20 % slower (574-599 ms against 691-740 ms, 300000 calls) and broke rooted slots, reverted. Root fix: the compiler emits the spread of a `Changing` result as store instructions.

`strict check` lets a second way of writing the same thing through (from the review of all DeltaEngine files, 2026-11-11, counts are DeltaEngine sites then):
- `ErrorCheckCannotFail` misses callees that turn every Error into a literal themselves: `current.Drawn(screen) is Error` where Drawn returns false on failure (Games/WebWars/WebWars.strict:61-72, ArenaHud.Draw, FractalPage.Published).
- `StatusNumberMustNotBeReturned` misses `condition then 1 else 0` results and `(a then 1 else 0) + (b then 2 else 0)` bit sums (about 30), a literal after only tests (`Failures Number` ending in `0` in every *Checks type), `-1` or a huge constant for nothing found (about 10), Number results only compared with `is 1` (Window.IsDebug, WebPage.Picture).
- Three ways to build a list: `mutable list = List(T)` + `for` + `list = list + item`, `List(Mutable(T))` + `.Add`, and the plain `for` expression (about 65 loops are pure maps or filters, `AccumulatingLoopMustBeForExpression`); `List(Number) + x` and `(x)` both build a one element list.
- A leading test line that does not mention the method it sits in (`TestMustCallItsOwnMethod`, 2377 test lines in Strict) and a method with a branch and no test that does no IO (`MethodWithBranchMustHaveTestOrBeIO`): written in `Validators/TestChecks.strict` (`Placed`), not in `Issues` until the lines are moved; instance and constant checks go to a `from` method with tests and `value` (works on the VM and natively).
- Tests and constants that write or list real files (`ArenaProfile.Empty.Saved` writes Profiles/Player.profile on every run, `constant Loaded = ArenaReplays(Directory.Files(...))`, engine tests loading game content in Graphics3D/Scenery.strict and Weapon.strict), about 15 (`TestMustNotTouchFiles`).
- The same call with arguments twice in a method outside the tests (`SameCallTwiceMustBeLet`): written in `Validators/RepeatedCalls.strict` (not wired), 879 sites in Strict (578 in Compiler); calls on `mutable` values must be skipped first (`Number.Fixed` changes `text` between two `IndexOf` calls).
- Two-number maximum and minimum by hand (`a > b then a else b`, 17 sites, several in GPU loops such as Softmax and Sampling): `(a, b).Maximum` would build a list per call and drop kernels, so `BaseMethodMustBeUsed` leaves them out until `Number` gets `Maximum(other)`/`Minimum(other)` (needs a decision). Substring to the end, IsBitSet, Lerp, Round, SquareRoot and `is not` are enforced since 2026-11-21.
