- A type with a `Generic` member is still the plain type in two places. Overloads of one name returning it with different member types (`Made(number Number) Holder` and `Made(name Text) Holder`): the VM passes, natively `Made(1).Shown` (`payload to Text`) is `()` without an error, ShapeTyping.Typed appends the instantiated type by name and Overloads.Returned picks the declared entry by ordinal. A member declared with it (`has holder Holder`, `holder.Sized`) stops the VM and the native build with `UnresolvedLink: Strict/Generic.Area`.
- An empty line inside a method stops `strict check` with `IndexOutOfRange` (`List(Text).First` in `FileCheck.IsUnimplemented`, Expressions/FileCheck.strict line 161) instead of a rule issue; a file starting with a UTF-8 BOM checks clean.
- `strict check` prints issues in two formats: the Validators rules as `<File>.strict:line N: Rule: detail`, the Expressions checks as `Rule: detail in <File>.strict:N` (README documents the first).
- `strict check .` is not clean: 51 `StatusNumberMustNotBeReturned` (Strict.strict 6, Compiler 23, Runtime 15, Networking/SocketChecks 7, NeuralNetworks/MachineUse 2), `MethodCountMustNotExceedLimit` in Validators/SureMethods (19 > 18), `MethodLengthMustNotExceedTwelve` in Expressions/FileCheck.UnknownMethods, two lines over 120 characters in Compiler/MlirChanged (26, 29).
- Indexing a Text constant (`HexDigits(n)`) crashes natively with AccessViolation, on the VM it works and `HexDigits(...) to Text` works natively (StrictComfy StrictGenHttp.Digits works around it).
- Test comparisons are approximate only at the top level: `x is 0` as a test line uses the Near helper, inside `(a) and (x is 0)` it is exact; `Both(0) is H3Vae.Pixels` on two native decodes of one latent failed with a relative error below 1e-5 (StrictComfy H3Decoding.strict line 8).
