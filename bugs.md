- An Error made with a value (`InvalidPattern(pattern)` of `constant InvalidPattern = Error`) returned from a method declared to return another type (`RegexPart`) comes back on the VM as an instance of that type built from the error's name text (`RegexPart((RegexStep(73, (I), ...)), InvalidPattern, InvalidPattern)`) instead of the Error; the plain `InvalidPattern` works (`Regex/RegexParser.strict`, 2026-11-14).
