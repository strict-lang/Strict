Per 8B token: 7.2 ms of kernels (`Layer.Sums` 5.5 ms at about 730 GB/s), 759 launches, the GPU idles 1-1.5 ms (0.4 ms host work before the first kernel, 45-170 us per graph launch, a new 64 MB device chunk every 6 steps). Also open: the expert routing of the MoE models on the GPU (Qwen3-Coder-30B-A3B), MXFP4 for gpt-oss, a `Range` loop on the device (its kernel started at 0), a conditional in a loop body keeps the loop serial (`MlirPurity`), per row `Summed` still checks its lists and matrix rows are separate allocations, only F32 safetensors are read (`OnlyFloat32TensorsAreSupported`). ## Language and compiler
- **Same-named types in one build**: a build needing `WebWars/Scene` and `LogoApp/Scene` at once is not supported (types and native symbols are keyed by the plain name).
- **Stack overflows show no Strict stack** and the other tests of the file do not run (a depth counter in the VM needs room in `Frame` and `Machine`, both at 15 members and methods).
- **`Code` of a Dictionary natively** links nothing (Dictionary methods are runtime helpers), `got:` uses `to Text` for dictionaries; needs code converters for `strict_pairs_text`.

## Rebalancing: exact values and C# integration (../Rebalancing)
Stepped decimals work for small values (README "Rules worth knowing", `Examples/Prices.strict`), libraries for Number, Text, Boolean, records of numbers as C structs and lists of numbers or records (`strict build X.strict library`, README "Command line"); Rebalancing uses the generated C# binding behind one host lock, policy coefficients cross as decimal text. Blocking the financial port (checked 2026-10-16): the generated scalar ABI is Double -> Double, so C# 12345678.12345678m comes back as 12345678.1234568m (0.00846253m and 82393.82m survive), and the Strict VM already fails the stepped identity within the documented range (2^51 steps):

```strict
Echo(amount Number with Step 0.00000001) Number with Step 0.00000001
	Echo(12345678.12345678) is 12345678.12345678
	amount
```

Needed: stepped values as exact int64 step counts (VM and native), generated decimal bindings with scale metadata for scalar, record and list arguments and results, explicit overflow outside the range. Then: lists of stepped values (`has prices Numbers with Step 0.01`), `let`/`mutable` locals with a step, lists of texts, Boolean record fields as C# bool, Strict calling C# host services. Acceptance: the ASP.NET host sends a candle/portfolio/settings snapshot, Strict returns proposed trades and reasons with decimal values unchanged, errors produce no orders, historical fixtures match the C# reference before its logic is removed.
