1. **Language models on the GPU** (asked 2026-10-15, RTX 4090 24 GB, Threadripper 3990X, 128 GB, what is done and measured is in `NeuralNetworks/README.md`): pass llama.cpp with the same GGUF weights and greedy sampling, Qwen3-8B Q4_K_M at batch 1 first (decode 7.5-8.0 ms per token against 7.3 ms, prefill one step of 7 ms per prompt token where llama.cpp batches 512 at 9413 tokens/s), then batch 8 x 4K. ## Language and compiler
- **Same-named types in one build**: a build needing `WebWars/Scene` and `LogoApp/Scene` at once is not supported (types and native symbols are keyed by the plain name).
- **Stack overflows show no Strict stack** and the other tests of the file do not run (a depth counter in the VM needs room in `Frame` and `Machine`, both at 15 members and methods).
- **`Code` of a Dictionary natively** links nothing (Dictionary methods are runtime helpers), `got:` uses `to Text` for dictionaries; needs code converters for `strict_pairs_text`.
- **`and`/`or` with a list operand is accepted**: `active >= 0 and (skills(active).name.StartsWith("Lance"))` is `Boolean and List` because `(x)` is a one-element list, the list (and its index -1) is built before `and`, the result is `(true)` on both backends (SoulCraft aborted natively with exit code 3). Operands of `and`, `or`, `xor` must be Booleans or Numbers, anything else should be a compile error naming the parentheses.
- **A constant named `Member` read through an instance is empty**: in a test of `Expressions/HiddenType`, `Counting.Member` (with `constant Member = SyntaxParser(...).Parse`) gave a node without children, `Member` alone worked (renamed to `Twiced`).
- **Package lookup misses ../Strict/Binary transitively**: a DeltaEngine/Physics3D type using Graphics3D/DeltaMesh (`has data BinaryData`) fails with `NameNotFound: BinaryData` until DeltaMesh declares `Binary/BinaryData`, SoulCraft resolves plain `BinaryData`.
- **Arc tangent of any number**: `Vector2(x, y).Atan` (atan2, degrees from +Y towards +X, `Vector2(1, 0).Atan is 90`) and `Ratio.Asin`, `Acos`, `Atan` are native on both backends, but `Ratio` is constrained to -1..1, so the arc tangent of a larger number needs `Vector2(value, 1).Atan`; the `Degrees(0)` body of `Vector2.Atan` is only the spec placeholder.
- A native runtime abort (index out of range) in a windowed exe exits with code 3 and prints nothing; print the error and Strict stack to stderr or a crash log next to the exe.

## Rebalancing: exact values and C# integration (../Rebalancing)
Stepped decimals (README "Rules worth knowing", `Examples/Prices.strict`) keep 12345678.12345678 at Step 0.00000001 and values up to 2^51 steps exactly (the rounding tolerance was over half a step above 2^49 steps), libraries for Number, Text, Boolean, records of numbers as C structs and lists of numbers or records (`strict build X.strict library`, README "Command line"); Rebalancing uses the generated C# binding behind one host lock, policy coefficients cross as decimal text. A stepped Number parameter or result is `decimal` in the generated C# (C# rounds an argument to its step and rounding mode like a Strict caller does, a result to whole steps, outside 2^51 steps the call throws an OverflowException `DecimalOverflow`). Still open: stepped record fields and lists as decimal, exact int64 step counts instead of doubles (needed for anything beyond 2^51 steps). Then: lists of stepped values (`has prices Numbers with Step 0.01`), `let`/`mutable` locals with a step, lists of texts, Boolean record fields as C# bool, Strict calling C# host services. Acceptance: the ASP.NET host sends a candle/portfolio/settings snapshot, Strict returns proposed trades and reasons with decimal values unchanged, errors produce no orders, historical fixtures match the C# reference before its logic is removed.
